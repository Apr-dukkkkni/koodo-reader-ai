## 长期记忆与回答深度自适应（Week 5）

Koodo Companion 会记住用户对每个概念的熟悉程度，并据此调整回答深度。

### 认知画像

- 每个"术语"（如"郡县制"）在 `concept_profile` 表中一行
- `familiarity_level` 取 0~3：
  - 0 = 完全陌生（白话 + 背景 + 例子）
  - 1 = 有基础（定义 + 例子 + 关键区别）
  - 2 = 比较熟悉（省略常识，直讲因果）
  - 3 = 很熟（细节、争议、概念边界）

### 反馈如何改变深度

| 用户操作              | familiarity 变化 |
| --------------------- | ---------------- |
| 连续 2 次 TOO_SHALLOW | +1               |
| 连续 2 次 TOO_DEEP    | -1               |
| JUST_RIGHT            | 不变             |
| 其他组合              | 不变             |
